# INETRIS · Proposta PlayCell

Página única e autocontida (`index.html`): CSS e imagens dentro do arquivo, sem JavaScript.
Fontes gratuitas do Google Fonts: Anton (títulos e números), Inter (textos, menu e botões) e IBM Plex Mono (rótulos).

## Publicar no GitHub Pages
1. Envie `index.html`, `README.md` e `.nojekyll` para a raiz do repositório (branch `main`).
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.

## Ajuste rápido
- **WhatsApp:** procure por `wa.me/` no `index.html` e confira o número (55 + DDD + número).
